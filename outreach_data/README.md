# Рассылка китайским продавцам

Отдельный контур: парсер собирает продавцов, этот модуль их оценивает,
сортирует и рассылает сообщения через чат Ozon с ограничителями.

## Порядок запуска

```bash
# 1. Собрать продавцов из результатов парсера в очередь
python run_outreach.py import

# 2. Посмотреть оценку (лучший — в конце списка)
python run_outreach.py score --top 30

# 3. Написать текст сообщения
cp outreach_data/templates/example.txt.example outreach_data/templates/main.txt
#    отредактировать main.txt, убрав метку «ЗАМЕНИТЕ ЭТОТ ТЕКСТ»

# 4. Проверить, как выглядит готовое сообщение
python run_outreach.py preview

# 5. Один раз снять разметку чата (нужно быть залогиненным в Ozon)
python run_outreach.py inspect
#    проверить outreach_data/selectors.proposed.json
#    и скопировать нужные значения в outreach_data/selectors.json

# 6. Проверить на одном продавце в режиме предпросмотра
python run_outreach.py send --dry-run --once

# 7. Рабочий цикл: одно сообщение в час
python run_outreach.py send --live
```

## Ограничители

Настраиваются в `outreach_data/sender.json`:

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `interval_minutes` | 60 | пауза между сообщениями |
| `interval_jitter_minutes` | 10 | разброс паузы (±) |
| `daily_cap` | 12 | потолок за сутки |
| `window_start` / `window_end` | 10:00 / 19:00 | рабочее окно, ночью не пишем |
| `max_attempts` | 2 | попыток на одного продавца |
| `dry_run` | true | показывать, а не отправлять |

Остановить рассылку в любой момент: создать файл `outreach_data/STOP`.
Отправщик проверяет его перед каждым сообщением.

## Что важно знать

**Дедупликация.** Одному продавцу пишем один раз, независимо от того,
сколько раз его нашли и сколько раз вы повторно запускали `import`.

**Стоп-лист.** Если продавец попросил не писать — `python run_outreach.py
optout <seller_id>`. Такой продавец исключается навсегда и не вернётся в
очередь при повторном импорте.

**Отправка идёт из вашего браузера.** Модуль подключается к Chrome с
постоянным профилем (`~/.ozon_parser_chrome`), где вы залогинены в Ozon.
Никаких паролей в конфигах.

**Селекторы чата нужно снять один раз.** Разметка чата Ozon закрыта
авторизацией, поэтому её нельзя прописать заранее. `inspect` открывает
карточку товара, раскрывает чат и сохраняет черновик селекторов —
проверьте его глазами перед первым запуском. Пока файла
`selectors.json` нет, живая отправка не запустится.

**Про риски.** Автоматизация действий в аккаунте Ozon противоречит
правилам площадки, а холодные рекламные сообщения в РФ требуют согласия
получателя (ст. 18 ФЗ «О рекламе»). Ограничители снижают вероятность
блокировки, но не устраняют её. Решение и ответственность — на вас.

## Модули

| Файл | Что делает |
|---|---|
| `src/outreach/scoring.py` | разбор метрик («106 K», «3 месяца») и оценка продавца |
| `src/outreach/queue_db.py` | SQLite-очередь: дедупликация, статусы, стоп-лист |
| `src/outreach/templates.py` | подстановка переменных в текст сообщения |
| `src/outreach/sender.py` | ограничители и отправка |
| `src/outreach/inspect_chat.py` | одноразовая разведка разметки чата |
| `test/test_outreach.py` | тесты разбора метрик и ограничителей |

## Формула оценки

```
score = 1.0 * log10(заказы + 1)
      + 0.6 * log10(отзывы + 1)
      + 0.05 * месяцев на Ozon
      + 2.0 * рейтинг
```

Логарифмы обязательны: разброс заказов от сотен до сотен тысяч, и без
сжатия один крупный продавец перевесил бы весь список. Веса можно менять
не трогая код:

```bash
python run_outreach.py score --weights '{"orders": 1.5, "rating": 0.5}'
```
